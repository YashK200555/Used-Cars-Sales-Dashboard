🚗 Resale Car Inventory Dashboard – Excel

📌 Project Overview

The Resale Car Inventory Dashboard is an interactive Excel-based data analysis project designed to analyze and visualize resale car inventory data.
The dashboard provides insights into car prices, inventory distribution, fuel types, transmission types, manufacturing years, and vehicle conditions. It helps users understand inventory trends and make data-driven business decisions.

🎯 Project Objectives

* Analyze resale car inventory data.
* Identify popular car companies and fuel types.
* Understand pricing trends across different companies.
* Analyze vehicle conditions and manufacturing years.
* Create an interactive dashboard for business reporting.

🛠️ Tools & Technologies

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Slicers
* KPI Analysis
* Data Cleaning
* Data Visualization

📊 Dataset Description

The dataset contains 1,000 resale car records with the following columns:

| Column             | Description                   |
| ------------------ | ----------------------------- |
| Car Company        | Manufacturer of the vehicle   |
| Car Model          | Model name of the car         |
| Manufacturing Year | Year the car was manufactured |
| KM Driven          | Total kilometers driven       |
| Car Age            | Age of the vehicle            |
| Price              | Resale price of the car       |
| Fuel Type          | Petrol, Diesel, CNG, etc.     |
| Colour             | Vehicle colour                |
| Transmission       | Manual or Automatic           |
| Features           | Available vehicle features    |
| Condition          | Overall vehicle condition     |
| Accident           | Accident history              |

📈 Dashboard Features

The dashboard includes the following analysis:

* Company-wise Average Price: Compare average resale prices across car manufacturers.
* Company-wise Car Count: Analyze inventory distribution by company.
* Fuel Type Analysis: Understand the distribution of cars by fuel type.
* Transmission Analysis: Compare manual and automatic vehicles.
* Condition-wise Average Price: Analyze pricing based on vehicle condition.
* Manufacturing Year Analysis: Identify inventory trends across manufacturing years.

Interactive Filters

* Manufacturing Year
* Car Company
* Car Condition

These slicers allow users to interact with the dashboard and explore specific categories of inventory.

💡 Key Business Insights

The dashboard helps users:

* Identify companies with higher average resale prices.
* Understand which car brands dominate the inventory.
* Analyze customer preferences for fuel and transmission types.
* Evaluate how vehicle condition affects resale prices.
* Identify the distribution of older and newer vehicles.
* Support inventory planning and pricing decisions.

🚀 How to Use

1. Download the Excel workbook from this repository.
2. Open it using Microsoft Excel.
3. Navigate to the Dashboard sheet.
4. Use the slicers to filter the inventory data.
5. Explore the charts and KPIs to understand resale car trends.

📌 Conclusion

This project demonstrates how Microsoft Excel can be used to transform raw resale car inventory data into meaningful business insights through data cleaning, Pivot Tables, KPIs, and interactive dashboard visualizations.

It provides a simple and effective solution for analyzing vehicle inventory and supporting data-driven decision-making.
